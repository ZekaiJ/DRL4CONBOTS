Analytical framework

Five regimes, five connected questions

The evidence map interprets a learned component inside the complete robot--learning--control configuration. It does not assign an ordinal readiness score.

Construction regimes

  • Earthwork and material processing
  • Structural assembly and installation
  • Material placement and lifting
  • Additive manufacturing and surface processing
  • Navigation, layout, and logistics support

Each regime is organized by the failure physics that govern the task, not by an algorithm leaderboard.

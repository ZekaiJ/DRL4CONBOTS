The scientific object

The complete command path

A task score does not show whether a learned component directly commands actuators, proposes a bounded reference, selects a skill, or advises an operator. Nor does it show what can intervene when execution departs from plan.

The review therefore compares each robot–task–learning–control configuration as a whole: failure physics, learned interface, execution authority, active protection, test conditions, and recovery.

Operational continuity

What must survive a learned action?

01

Work changes

Motion alters material, geometry, dynamics, access, or workflow state.

02

A proposal forms

The learned component produces a command, reference, skill, or plan.

03

Execution is mediated

Controllers, constraints, supervisors, or people authorize physical action.

04

A viable state remains

The machine and work state remain usable or are restored after disturbance.

05

Work continues

The next task action can proceed without an unreported reset or rescue.
